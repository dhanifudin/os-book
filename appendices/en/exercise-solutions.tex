\section{Solutions for Chapter 1: Introduction to Operating Systems}

\subsection{Exercise 1.1}
\textbf{Question:} Explain the difference between proprietary and open-source operating systems.

\textbf{Answer:}
\begin{itemize}
    \item \textbf{Proprietary OS:} Operating system with closed source code owned by
          a specific company. Examples: Windows, macOS. Users must pay for licenses
          and cannot modify the source code.

    \item \textbf{Open-source OS:} Operating system with source code that is open
          to the public. Examples: Linux, FreeBSD. Users can view, modify,
          and redistribute source code according to applicable licenses.
\end{itemize}
