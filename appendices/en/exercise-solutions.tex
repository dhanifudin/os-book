\section{Solutions for Chapter 1: Introduction to Operating Systems}

\subsection{Exercise 1.1}
\textbf{Question:} Explain the difference between proprietary and open-source operating systems.

\textbf{Answer:}
\begin{itemize}
    \item \textbf{Proprietary OS:} An operating system whose source code is closed and
          owned by a specific company. Examples: Windows, macOS. Users must
          pay for a license and cannot modify the source code.

    \item \textbf{Open-source OS:} An operating system whose source code is open
          to the public. Examples: Linux, FreeBSD. Users can view, modify,
          and redistribute the source code according to the applicable license.
\end{itemize}
